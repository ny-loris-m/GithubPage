Projekt: Webshop mit einfachem Warenkorb

Diese Projektbasis enthält:
- Startseite, Produktübersicht, Produktdetail, Kontakt, Warenkorb
- Einfacher Warenkorb mit localStorage (js/cart.js)
- Produktdaten in data/products.json (10 Beispielprodukte)

Optional: Weiteres Styling, Bilder-Videos ersetzen, Deployment (z.B. GitHub Pages).
